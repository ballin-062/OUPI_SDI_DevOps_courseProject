# Project Name : "Somehow I manage" -- The Michael Scott Task Manager

## Project Description:
This project aims to create a task manager web application for students, office workers, and anyone who values their time.
Borrowing from the most legendary Office Manager, Michael Scott, we leverage only state-of-the-art methods for managements across Fortune 1,000,000 companies.

## Planned Technology Stack
- Programming Language: Python
- Framework: Django
- Database: Postgresql
- Testing Framework: PyTest (pytest-django)
- CI/CD Platform: GitHub Actions
- Deployment Target: Docker container on a cloud VM (e.g., DigitalOcean Droplet or AWS EC2)

1. Demonstrate a professional workflow using industry best practices for DevOps

3. Create a useful full-stack web application
4. Gain experience with DevOps methodologies and terms
5. Have FUN!
