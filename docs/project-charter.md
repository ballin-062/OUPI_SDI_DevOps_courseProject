“Somehow I Manage” -- The Michael Scott Task Manager 



Project Charter 



**Purpose and Goals:** 



The purpose of this project is to create a fun and interactive task tracker/manager. This allows the team members to apply what we learn about DevOps throughout the semester in a hands-on manner. 



&#x20;



**Problem:** 



Existing project management platforms provide extensive functionality that can be unnecessarily complex for small teams, students, and personal projects. This project aims to provide a simple and engaging task managing experience while integrating software development and DevOps concepts directly into the platform. 



&#x20;



**Product Objectives:** 



**Develop a functional application that allows users to:** 



&#x09;Create and manage boards 



&#x09;Create, edit, and delete tasks 



&#x09;Move tasks between workflow columns 



&#x09;Assign tasks to team members 



&#x09;Set task priorities 



&#x09;Add labels and due dates 



&#x09;Track task status 



&#x09;Add comments or notes 



&#x09;View project progress 



**Optional features may include:** 



&#x09;XP for completing tasks 



&#x09;Levels 



&#x09;Achievements 



&#x09;Task streaks 



&#x09;Boss tasks 



&#x09;Team leaderboards
